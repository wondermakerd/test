# How to upload this portfolio to GitHub

## What GitHub is for here

The live portfolio is a website: [alisa-product-marketing.wondermake.chatgpt.site](https://alisa-product-marketing.wondermake.chatgpt.site). GitHub is the companion repository that stores the README, CV, screenshots and case evidence in an organised, versioned place.

You do not need GitHub for the website to work. Send the live portfolio URL to recruiters. Use the GitHub repository when a company asks for a GitHub profile, wants to inspect your work files, or you want a durable backup and a shareable evidence pack.

## Upload in the browser

1. Sign in at [github.com](https://github.com) and click **New repository**.
2. Name it `alisa-product-marketing-portfolio`.
3. Choose **Private** if the CV, screenshots or Airtable links should be visible only to people you invite. Choose **Public** only when you are comfortable making those materials searchable.
4. Create the empty repository without adding another README.
5. Download and unzip `Alisa_Gron_GitHub_Portfolio_Package_v5.zip` on your computer.
6. Open the new repository, click **Add file → Upload files**, and drag in the unzipped contents — upload the `README.md`, `links.md`, `GITHUB_UPLOAD.md`, `assets/` folder and the CV PDF. Do not upload only the ZIP; GitHub will not display the portfolio contents properly inside an archive.
7. Enter the commit message `Add product marketing portfolio` and click **Commit changes**.
8. Open the repository’s `README.md` page and check the images, live portfolio link, MISIS link and Bella & Bona Airtable links.

## Important distinction

This package is a polished evidence repository, not the source code of the hosted Sites application. GitHub will display it as a professional portfolio repository. The interactive visual experience remains on the live portfolio URL above.

If a recruiter asks for one link, send the live portfolio. If they ask for GitHub, send the repository URL as a second link.

## Airtable access

The Bella & Bona Airtable links are private workspace links. A recruiter will need an Airtable account with access to open them. If you want external recruiters to see the tables, create a separate read-only Airtable shared view and replace the two links in `README.md` and `links.md` with those public-view URLs.
